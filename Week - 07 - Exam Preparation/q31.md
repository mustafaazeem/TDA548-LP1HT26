# Q3: Drones and charging stations

In this question you will model a fleet of delivery drones and charging stations.

![Drones](./drones.png)

Fully charged drones have a range of 15 km.
As they travel around they use up their batteries and their range decreases. At some point they will need to dock at a station to recharge.
There are various stations available in different locations.
In order for a drone to reach a particular station, it needs to be within the drone's range.
Each station has space for a limited number of drones at a given time. We call this number the _capacity_ of the station. If a station is full then a drone cannot dock there.

Your task is to model this scenario by implementing the classes `Station` and `Drone`, described below.

### Implement a Python class `Station` (8p)

The class should have the following instance variables:

- `loc`: the location of the station (two-dimensional coordinate)
- `capacity`: the capacity of the station (positive integer)
- `drones`: which drones are docked at this station

The class should have the following methods:

- `__init__(self, loc, capacity)` (0p)
   Initializes the station with the given location and capacity.

- `available(self)` (2p)
   Returns an integer indicating how many places are available at this station.
   If the station is full, this should return 0.

- `dock(self, drone)` (2p)
   Attempts to dock `drone` at this station, returning `True` if successful or `False` if there is no space available.

- `recharge(self)` (4p)
   Recharges all the drones docked at this station to their maximum range (15 km).

### Implement the class `Drone` (17p)

The class should have the following instance variables:

- `loc`: the current location of the drone (two-dimensional coordinate)
- `range`: the drone's current range
- `station`: the station where this drone is docked at, or `None` if the drone is not docked

The class should have the following methods:

- `__init__(self, loc)` (0p)
   Initializes the instance variables.
   The drone is located at `loc`, with maximum range (15 km) and not docked.

- `distance_to(self, loc)` (3p)
   Calculates the distance between the drone and location `loc`, returning a positive float.
   The distance d between two points (x₁,y₁) and (x₂,y₂) can be calculated using Pythagoras' theorem: d² = (x₂-x₁)² + (y₂-y₁)²

- `reaches(self, station)` (2p)
   Returns a boolean, indicating whether this drone can reach `station` or not.

- `move(self, loc)` (6p)
   Attempts to move the drone to the location `loc` (in a straight line).
   Before moving, the drone must check that it has enough range to reach the location.
   If so, update the state and return the distance travelled.
   If not, print "cannot reach location", stay in the current location and return 0.
   Note: If the drone is currently docked, then it should undock first.

- `dock(self, station)` (6p)
   Attempts to dock this drone at `station`.
   Before attempting docking, the drone must check the following conditions:
   - already docked
   - cannot reach station
   - station full
   If any of the above conditions is true, print the corresponding message from the above list and return, without moving the drone.
   Otherwise, move to the station, update the state of the program appropriately and print "successfully docked".

### Example run

```
>>> s1 = Station((3,2), 1)
>>> s2 = Station((8,6), 2)

>>> d1 = Drone((0,0))
>>> d1.move((3,7))
7.615773105863909
>>> d1.move((4,4))
3.1622776601683795
>>> d1.dock(s2)
cannot reach station
>>> d1.dock(s1)
successfully docked

>>> d2 = Drone((10,0))
>>> d2.move((6,3))
5.0
>>> d2.dock(s1)
station full
```
